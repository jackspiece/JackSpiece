## Selected work

### Maintainer Radar

A read-only Python CLI and GitHub Action that turn pull request metadata into an explained, time-boxed review plan. The browser demo uses a fictional queue or five recent public PRs. Suggestions expose their evidence and leave the review decisions with the maintainer.

**[Try the demo →](https://jackspiece.github.io/maintainer-radar/)** · [Code and quick start](https://github.com/jackspiece/maintainer-radar) · [Case study](docs/case-studies.md#maintainer-radar)

### Decap CMS · GitLab reliability

Four merged upstream fixes cover LFS media loading, expired PKCE token refresh, GraphQL Bearer authentication, and shared refresh handling for GraphQL and REST 401 responses. The [contribution record](docs/contributions.md#decap-cms) links each patch and its merge date.

**[Read the reliability case study →](docs/case-studies.md#decap-cms)** · [Latest merged fix: #7932](https://github.com/decaporg/decap-cms/pull/7932)

### CSV Cleanup

Turn a CSV export into cleaned data, review rows and a change report. IDs stay text, and trimming and exact deduplication are optional.

**[See the example report →](https://jackspiece.github.io/csv-cleanup-example/)** · [Code and quick start](https://github.com/jackspiece/csv-cleanup-example)

### n8n Intake

An importable seven-node workflow with original records, review queues and a reconciliation count. Its fictional example accounts for all eight inputs. Duplicate detection is scoped to one run; a live integration would need persistent checks.

**[View the workflow →](https://github.com/jackspiece/n8n-intake-example)** · [Recorded n8n execution](https://github.com/jackspiece/n8n-intake-example/actions/runs/34645429890)

## Smaller studies

- **[Studies in Light](https://jackspiece.github.io/gallery-layout-example/)**: a responsive HTML, CSS and JavaScript gallery with four credited public domain Monet paintings. [Code and layout notes](https://github.com/jackspiece/gallery-layout-example).
- **[Encoder Review](https://github.com/jackspiece/encoder-review-example)**: a bounded functional check of one published byte-to-hex encoder against an independent reference. The [September 11, 2026 record](https://github.com/jackspiece/encoder-review-example/blob/main/results/2026-09-11.json) contains 65,976 cases, the source fingerprint and the limits of the result.
- **[Email retries and idempotency](articles/email-retries-2026-10-01/README.md)**: an AI-written technical demonstration with a local SQLite experiment, nine tests and explicit limits. It sends no email.

The data examples use fictional records. The gallery credits its artwork, and the encoder review identifies the third-party implementation separately from the checking harness.
